Attributions

Last updated: September 26, 2026

beyondefinition is built mostly from scratch, but it relies on a few outside services and open-source assets. They're listed here along with the license or terms that apply to each, as best as they could be identified from the site's own code.

Fonts

Fraunces, designed by Phaedra Charles and Flavia Zimbardi of Undercase Type, and Source Serif 4, designed by Frank Grießhammer for Adobe — both used for the site's headings and body text, served through Google Fonts. Both are released under the SIL Open Font License 1.1, which permits free use in a project like this one; this credit is included as good practice rather than a strict requirement of the license. Loading fonts from Google's servers sends your browser's IP address to Google as part of the request — see Google's Privacy Policy.

Backend & storage — Supabase

The site's database, user-uploaded media storage, sign-in for the site owner, and a couple of small backend functions (like the interactive chat) run on Supabase. This is an infrastructure relationship rather than a creative-content one — see Supabase's Terms of Service and Privacy Policy for what governs data passing through it.

Hosting — Render

The site is hosted on Render. See Render's Terms of Service and Privacy Policy.

Music search & previews — Apple

The "add a song" search uses Apple's public iTunes Search API and plays back the short preview clip Apple provides for each track, streamed directly from Apple's servers. No song audio is downloaded, stored, modified, or redistributed by this site. This use is subject to Apple's own terms, including the Apple Media Services Terms and Conditions.

Interactive chat feature — Groq

The interactive chat/companion feature (the pet-chat backend function) is powered by Groq, which runs the language model that generates its replies. Messages you send to the companion are processed by Groq's API to generate a response. See Groq's Terms of Use and Privacy Policy.

Icons & artwork

The site's icons, illustrations, and small animations (the envelope mark, the companion character, and the interface icons) are inline, hand-drawn SVG code written directly into the page. No icon font, icon CDN, or stock-art library is loaded anywhere in the site — so unlike the items above, nothing here comes from an outside source or needs a license credit.

(If new artwork is added later that does come from somewhere else — a purchased icon set, a commissioned illustration, a stock template — list it here with its license when that happens.)

User-submitted content

Text, photos, gifs, videos, and songs posted by visitors remain the property of whoever posted them. See the Copyright & Content Policy for the rules around what can be uploaded, and how to report content that shouldn't be here.
